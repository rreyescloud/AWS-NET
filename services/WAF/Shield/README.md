# Shield — DDoS Protection

## Enterprise Experience

Managed Shield Advanced deployments for enterprise customers requiring DDoS protection for public-facing applications. Engaged with the DDoS Response Team (DRT) during active attacks and configured proactive protections for high-traffic events.

Key highlights:
- Engaged **DRT during active DDoS attacks** on NLB Elastic IPs and CloudFront distributions
- Investigated **unauthorized Shield activation** ($3,000/month) — identified user via CloudTrail, recommended SCPs
- Planned **Shield Advanced migration between Organizations** with protection continuity
- Clarified **Shield cost waiver** — only applies to resources explicitly protected, not all account resources
- Configured **pre-event preparation** for expected traffic spikes
