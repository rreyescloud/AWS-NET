# Amazon Route 53

## Overview

Amazon Route 53 is a highly available and scalable Domain Name System (DNS) web service. It performs three main functions:
- Domain registration
- DNS routing
- Health checking

## DNS Fundamentals

DNS (Domain Name System) translates human-readable domain names into IP addresses that computers use to identify each other on the network.

### DNS Resolution Flow
1. Client queries a recursive resolver
2. Resolver queries root nameservers
3. Root directs to TLD nameservers (.com, .org, etc.)
4. TLD directs to authoritative nameservers
5. Authoritative nameserver returns the IP address

## Record Types

| Record Type | Description |
|---|---|
| **A** | Maps a domain to an IPv4 address |
| **AAAA** | Maps a domain to an IPv6 address |
| **CNAME** | Maps a domain to another domain name (cannot be used at zone apex) |
| **ALIAS** | Route 53-specific record that maps to AWS resources (can be used at zone apex) |
| **MX** | Specifies mail servers for the domain |
| **TXT** | Contains text information (used for SPF, DKIM, domain verification) |
| **NS** | Identifies the nameservers for the hosted zone |
| **SOA** | Start of Authority - contains administrative information about the zone |
| **SRV** | Specifies the location of servers for specific services |
| **CAA** | Specifies which certificate authorities can issue certificates for the domain |
| **PTR** | Used for reverse DNS lookups |

### SPF Records (TXT)

SPF is an email authentication method designed to detect and prevent email spoofing. SPF record format example:
```
"v=spf1 include:_spf.google.com include:amazonses.com ip4:192.0.2.0/24 ~all"
```

Common SPF mechanisms:
- `include:` - Authorizes servers specified in another domain's SPF record
- `ip4/ip6:` - Specifies IP addresses or ranges authorized to send mail
- `a:` - Authorizes the A record of the current domain
- `mx:` - Authorizes the MX records of the current domain

## Alias vs CNAME

| Feature | ALIAS | CNAME |
|---|---|---|
| Zone apex | Yes | No |
| DNS query charge | Free for AWS resources | Standard charges apply |
| Record type | Can coexist with other records | Cannot coexist with other records for same name |
| Targets | AWS resources only | Any domain name |
| TTL | Set by Route 53 | Configurable |

**Important:** You cannot create a CNAME record for a domain apex (zone apex). For example, if you register `example.com`, the apex is `example.com` and you cannot create a CNAME for it. Use an ALIAS record instead.

## Routing Policies

### Simple Routing
- Maps a domain to one or more IP addresses
- If multiple values are returned, client chooses one at random
- No health checks associated

### Failover Routing
- Active-passive configuration
- Routes traffic to primary resource when healthy
- Routes to secondary (standby) resource when primary is unhealthy
- Requires health check on primary record

### Weighted Routing
- Distribute traffic across multiple resources based on assigned weights
- Weight of 0 stops traffic to that resource
- Useful for blue-green deployments and A/B testing

- Weighted routing - https://docs.aws.amazon.com/Route53/latest/DeveloperGuide/routing-policy-weighted.html
- Values specific for weighted records - https://docs.aws.amazon.com/Route53/latest/DeveloperGuide/resource-record-sets-values-weighted.html
- Values specific for weighted alias records - https://docs.aws.amazon.com/Route53/latest/DeveloperGuide/resource-record-sets-values-weighted-alias.html

### Latency-Based Routing
- Routes to the resource with lowest latency for the user
- Latency is measured between AWS Regions and the user
- Can be combined with health checks

### Geolocation Routing
- Routes based on geographic location of the user
- Can specify by continent, country, or state (US)
- Default record handles queries from locations not mapped
- Uses MaxMind database: https://www.maxmind.com/en/home
- Configure geoproximity routing: https://repost.aws/knowledge-center/route-53-geoproximity-routing-console

### Geoproximity Routing
- Routes based on geographic location of resources and users
- Optionally shift traffic with bias values
- Requires Route 53 Traffic Flow

### Multivalue Answer Routing
- Returns up to 8 healthy records for each DNS query
- Not a substitute for a load balancer
- Can associate health checks with each record

## Hosted Zones

### Public Hosted Zone
- Contains records that specify how to route traffic on the internet
- Created automatically when registering a domain with Route 53
- Can be created for domains registered elsewhere

### Private Hosted Zone
- Contains records for routing traffic within VPCs
- Must be associated with at least one VPC
- VPCs must have `enableDnsHostnames` and `enableDnsSupport` set to true

## TTL Behavior

When using Amazon Provided DNS (Route 53 Resolver) within your VPC, if you send a DNS query with a TTL value exceeding 300 seconds, the response will always have a capped TTL of 300 seconds. This is deliberate behavior to optimize performance and ensure quick updates to DNS records.
